# Дифуры 1D — песочница

Открой `index.html` в браузере. Никакой сборки и сервера не нужно.

Система уравнений пишется в поле сверху (по одному уравнению в строке).
В поле всё подсвечено по смыслу: **поле красится цветом своей кривой** на
графике (хвост производной — тем же цветом побледнее), константы — сиреневым,
функции — зелёным, `x, t, pi` — серо-синим, комментарии `# …` — серым.
Слева от поля — список готовых задач; наведи на пункт — справа появится формула
в привычной записи: деление этажеркой с чертой, степень верхним индексом,
корень под радикалом, система под фигурной скобкой (скобка рисуется ровно по
высоте системы, а не подбирается кеглем). Цвета в формуле те же, что в поле
ввода. Как только текст
перестаёт совпадать с любой из задач, в списке загорается «своё уравнение».
Текст проверяется прямо во время набора: место ошибки подчёркивается волной,
а кнопка «Применить» гаснет, пока в поле нет изменений. При применении текст
приводится к единому виду — лишние пробелы убираются, `;` разводит уравнения
по строкам. Применённая система разбирается
и решается псевдоспектрально (FFT по x) схемой **ETDRK4** —
экспоненциальный интегратор 4-го порядка. Диагональная линейная часть с
постоянными коэффициентами считается точно экспонентой, поэтому жёсткие члены
вроде `uxxx` или `uxxxx` не ограничивают шаг по времени. Границы периодические,
нелинейность защищена фильтром 2/3.

```
utt = -v*ut
vt  = -V*ut
zt  = -u*v*vxx*ux
```

## Поля и константы

**Поле** — одиночная буква, у которой где-то есть производная по времени
(`ut`, `vt`, `ztt`). Для каждого поля должно быть ровно одно уравнение.
**Любая другая буква — константа** с ползунком в логарифмической шкале
(10⁻⁴…10³) и кнопкой знака. В примере выше `u`, `v`, `z` — поля,
`V` — константа (регистр важен).

Порядок по времени любой: `utt`, `uttt`. Он понижается автоматически —
поле порядка m даёт m компонент состояния (`u`, `ut`, `utt`…), у каждой
свои начальные данные и свой цвет/пунктир на графике.

| Запись | Смысл |
|---|---|
| `ut`, `utt`, `uttt` | производные по времени |
| `ux`, `uxx`, `uxxx`, … | производные по x любого порядка |
| `uvvxxux` | `u*v*vxx*ux` — знак умножения можно опускать |
| `u^2`, `2u`, `0.5*ux` | степени и числовые коэффициенты |
| `x`, `t`, `pi` | координата, время, π |
| `sin cos tan exp log sqrt abs tanh sinh cosh sech sign` | функции |

Смешанные производные (`uxt`) не поддерживаются — парсер скажет об этом прямо.
Старшая производная по времени должна входить линейно, с постоянным
коэффициентом (`u*ut = ux` будет отвергнуто).

Если старшая производная по x входит со «злым» знаком (`ut + uxx = 0` —
обратная диффузия), в шапке загорается предупреждение: задача некорректна,
решение обязано разойтись. Ровный по k рост (реакция вида `+u`) — это
нормально, на него не ругаемся.

## Когда горб опрокидывается

У `ut + u*ux = 0` вершина горба едет быстрее подошвы, профиль укручается и
за конечное время становится **разрывным**. Разрыв ряду Фурье не по силам: он
отвечает пилой на всю сетку, и она съедает решение (амплитуда даже растёт, хотя
у настоящего решения падать обязана).

Кнопка **«∿ гасить осцилляции»** добавляет гипервязкость в верхушку спектра:
пила гаснет, разрыв размазывается на пару ячеек, дальше считается нормальная
ударная волна. Гашение привязано к шагу сетки и к амплитуде, поэтому от `dt` и
от `N` ответ не зависит, а `∫u dx` сохраняется точно.

Кнопка отдельная и по умолчанию выключена, и это не лень: гасить всегда нельзя.
Разрыв в принципе непредставим в Фурье, так что любая защита — это подмена
задачи её вязкой версией, а такое решают за себя сами. К тому же осцилляции
не всегда паразитные: у КдФ и синус-Гордона рябь после укручения — это и есть
решение (распад горба на солитоны), и её гасить нельзя. Выбранная сила подобрана
так, чтобы солитоны КдФ уцелели дословно, но полагаться на это вслепую не стоит —
строка **«гашение»** в диагностике показывает, сколько энергии фильтр снимает
за единицу времени. На разрешённом решении там 10⁻⁸ %, на опрокидывании ≈5 %.

Пресет «★ Опрокидывание горба» — посмотреть на разницу: выключи кнопку и запусти.

## Мышь

Рисование идёт по **выбранному полю** (фишки в панели «Поля»: клик — выбрать,
кружок — показать/скрыть).

* **тянуть вверх/вниз** — амплитуда профиля (значение под курсором);
* **тянуть вбок** — полуширина;
* **колесо** — ширина;
* **Alt** (или галочка «складывать») — добавить профиль к текущему,
  так собираются два солитона для столкновения;
* «рисовать на ходу» — не сбрасывать время, подкидывать возмущение
  прямо в идущее решение;
* пока кнопка мыши нажата, счёт стоит — профиль не уезжает из-под курсора;
  отпустил — решение побежало дальше;
* инструменты выбираются кнопками-миниатюрами (на каждой нарисован тот профиль,
  который она рисует): шапочка (sech²), гаусс, ступенька, синус, константа,
  перо, шум. Что делает кнопка — написано во всплывающей подсказке.

Нижняя панель — диаграмма x–t для выбранного поля: время идёт вниз,
наклон полосы = скорость волны.

<kbd>пробел</kbd> — пуск/пауза, <kbd>R</kbd> — сброс к начальным данным (счёт при этом
останавливается),
<kbd>Ctrl</kbd>+<kbd>↵</kbd> — применить уравнения.

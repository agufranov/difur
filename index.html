Шпаргалка

      

        Каждое уравнение — с новой строки. Поля — одиночные буквы, у которых есть
        производная по времени: ut, vt, ztt.
        Порядок по времени любой: utt, uttt — понижается автоматически,
        появляются компоненты ut, utt с собственными начальными данными.

        По x: ux, uxx, uxxx…. Умножение можно опускать:
        uvvxxux = u*v*vxx*ux.

        Остальные буквы — константы с ползунком (логарифмическая шкала).
        Ещё есть x, t, pi, функции sin cos exp tanh sech abs sqrt,
        степени u^2. Границы периодические: область — это кольцо, и волна,
        ушедшая за правый край, влетает слева. «Запас за окном» в «сетке и шаге» делает
        кольцо длиннее экрана, чтобы это случилось не сразу.

        i — мнимая единица: ut = i*uxx это Шрёдингер. У такого поля
        на графике рисуется |ψ|, а цвет вдоль кривой — фаза; «импульс k₀»
        задаёт eik₀x, и пакет едет со скоростью 2k₀. Ограничений нет:
        i*ut + uxx + 2*abs(u)^2*u = 0 — солитон, который не расплывается,
        - x^2*u добавляет ловушку. Для комплексного поля есть
        abs conj re im arg — эти пять всегда вещественны.

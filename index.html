Шпаргалка

      

        Каждое уравнение — с новой строки. Поля — одиночные буквы, у которых есть
        производная по времени: ut, vt, ztt.
        Порядок по времени любой: utt, uttt — понижается автоматически,
        появляются компоненты ut, utt с собственными начальными данными.

        По x: ux, uxx, uxxx…. Умножение можно опускать:
        uvvxxux = u*v*vxx*ux.

        Остальные буквы — константы с ползунком (логарифмическая шкала).
        Ещё есть x, t, pi, функции sin cos exp tanh sech abs sqrt,
        степени u^2. Границы периодические.
